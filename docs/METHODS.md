# Generation and performance comparison

Only `UCI_Credit_Card.csv` is used. It has 30,000 records, 23 explanatory variables and target `default.payment.next.month`. ID is excluded. Categorical columns are SEX, EDUCATION, MARRIAGE and the six repayment-status variables. Observed category codes and negative bill balances are retained.

For each of five seeds, duplicate feature groups stay together in approximately 60/20/20 real training, validation and test partitions. Scaling and encoding are fitted on real training data. Synthetic rows are generated from training defaults and appended only to training; all original training records remain. Each method adds majority-minus-minority rows, giving balanced augmented training sets.

AGSS interpolation uses training-only numeric standardization, one-hot categories, PCA retaining 85% variance, and DBSCAN with minimum samples 12. Distance quantiles .65/.80/.95 are compared using interpolation augmentation and a fixed small classifier on real validation data. The selected rule is reused for cluster-conditioned diffusion. No extra clusters or prescribed noise percentages are invented. Interpolation uses within-cluster neighbors, a .05 perpendicular numeric perturbation, and source-parent categories. Those mixed-data details are project adaptations.

Diffusion uses the pinned official TabDDPM stochastic Gaussian/multinomial variational loss. Numerical variables use a training-only normal quantile transform. The MLP denoiser has two 128-wide hidden layers; the Transformer has one token per feature, width 32, four heads and one encoder layer. The sampling adapter bounds predicted clean numerical states to training quantile support. Categories are sampled as discrete states, not rounded nominal codes.

Training uses AdamW .001, weight decay .0001, gradient clipping 1, batch size 512 and 100 cosine timesteps. Each candidate trains incrementally to 50 and 150 epochs. Full-budget validation average precision selects the checkpoint; no test score selects a generator. Conditional diffusion fits retained defaults and samples clusters with square-root-count allocation. Interpolation allocates equally across retained clusters. These are documented adaptations, not exact replications of published benchmarks.

All generated datasets are compared using the same four classifiers and real test records within each split. Metrics are default-class average precision, ROC-AUC, F1, precision, recall, accuracy and balanced accuracy, with confusion counts. Scores at .5 and a validation-selected F1 threshold are retained. Threshold search uses .05–.95 in .01 steps; ties choose the lowest cutoff. Reported means and standard deviations are descriptive because repeated partitions overlap.

Primary references: [UCI dataset, Yeh (2009), CC BY 4.0](https://archive.ics.uci.edu/dataset/350/default+of+credit+card+clients); [TabDDPM](https://proceedings.mlr.press/v202/kotelnikov23a.html); [AGSS method](https://www.researchgate.net/publication/399275739_Credit_Card_Fraud_Detection_using_Deep_Learning_Techniques_And_Handling_Unbalanced_Class_Distributions_with_AGSS); [feature-token Transformer work](https://proceedings.neurips.cc/paper_files/paper/2021/hash/9d86d83f925f2149e9edb0ac3b49229c-Abstract.html). The pinned third-party code and its original license are under `vendor/tab_ddpm/`.

For the grounded rerun, all candidate validation predictions are saved, not only the AP values. The verifier recomputes these APs, checks the selected maxima, reconstructs epoch objectives from batch loss components, matches duration fields to monotonic-clock events, checks actual fitted classifier parameters, and compares our count formulas with independent scikit-learn calls. No earlier scores are silently reused. The requested matrix and hyperparameters are unchanged.
